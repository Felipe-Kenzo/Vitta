## User Story

**Título:** Acesso simples a serviços públicos para pessoas idosas

**Descrição:**
Como pessoa idosa com pouca familiaridade digital, quero consultar um guia com passo a passo simples, documentos necessários e locais de atendimento, para conseguir acessar serviços públicos sem depender de terceiros.

**Critérios de aceite:**
- Lista de serviços em linguagem simples
- Letra ajustável e alto contraste
- Leitura em voz alta
- Aplicação publicada na Azure
